# Contributing to DevGuess

Thanks for your interest in contributing.

## Contribution model

- This project uses a fork + pull request workflow.
- Direct pushes to `main` and `deploy` are restricted to the project owner.
- All changes must go through a pull request.

## How to contribute

1. Fork the repository.
2. Create a feature branch in your fork.
3. Make your changes.
4. Run checks locally:
   - `npm test`
   - `npm run build`
5. Open a pull request against `main`.
6. Participate in review if requested.

## Review process

- Pull requests may be reviewed by the community.
- Final approval and merge are performed by the project owner.

## Scope

- Bug fixes, documentation updates, and small features are welcome.
- Open an issue before starting large features.
