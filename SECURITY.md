# Security Policy

## Reporting a vulnerability

If you discover a security issue, do not open a public issue.
Report it privately at `security@devguess.io`.

Please include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Impact and affected area
- Any suggested mitigation

## Disclosure process

- Initial acknowledgement target: 3 business days
- Fix and disclosure timing depends on severity and complexity
- Please keep details private until a fix is released
